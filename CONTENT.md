# Customize your portfolio content

Replace placeholder values in `src/main/resources/static/index.html` and swap image files under `assets/images/`.

## Checklist

- [ ] **Hero** — Name, role, tagline, profile photo
- [ ] **Social links** — GitHub, LinkedIn URLs
- [ ] **Email** — Confirm contact email is correct
- [ ] **About** — Your personal story
- [ ] **Education** — University, college, and high school names, dates, bullets
- [ ] **Achievements** — Real awards and years
- [ ] **Certifications** — Courses from Coursera, Udemy, freeCodeCamp, etc.
- [ ] **Skills** — Update chip lists
- [ ] **Projects** — Titles, descriptions, tech, demo/repo URLs
- [ ] **Testimonials** — Real quotes from mentors (replace placeholder experts)
- [ ] **Resume** — Replace `src/main/resources/static/assets/resume.pdf`

## Image paths

| `assets/images/projects/project-2.jpg` | Task Manager API header |
| `assets/images/projects/project-3.jpg` | Weather Dashboard header |
| `assets/images/testimonials/expert-1.jpg` | Testimonial avatar |
| `assets/images/testimonials/expert-2.jpg` | Testimonial avatar |
| `assets/images/testimonials/expert-3.jpg` | Testimonial avatar |

Keep the same filenames when replacing images so you do not need to edit HTML.
